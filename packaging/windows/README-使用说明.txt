Insta Library for Windows x64
==============================

系统要求
--------
- 64 位 Windows 10 或 Windows 11
- 不需要安装 Python、Node.js 或 Insta360 官方 App

启动方式
--------
1. 完整解压 ZIP 文件，不要只在压缩包预览窗口里运行。
2. 让电脑连接 Insta360 相机发出的 Wi-Fi。
3. 双击“Insta Library.cmd”。
4. 浏览器打开后，点击“连接相机”。

关闭方式
--------
在网页右上角点击“断开并退出”。后台服务会同时关闭，不需要打开任务管理器。

常见问题
--------
- Windows 首次运行可能显示安全提醒，这是未使用商业代码签名证书导致的。
- 若浏览器没有自动打开，请访问 http://localhost:3000/
- 若应用无法连接相机，请确认当前 Wi-Fi 是相机热点，并暂时关闭会接管路由的 VPN。
- 请保持 Resources 文件夹与启动文件在同一目录，不要单独移动启动文件。

本项目为独立互操作研究项目，并非 Insta360 官方产品。目前控制通道坚持只读边界。
